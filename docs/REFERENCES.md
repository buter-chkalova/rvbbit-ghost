# Upstream references

The release configuration and security design were reviewed against these upstream documents:

- [Whonix for Windows and VirtualBox](https://www.whonix.org/wiki/Windows)
- [Whonix system requirements](https://www.whonix.org/wiki/System_Requirements)
- [Whonix host operating system selection](https://www.whonix.org/wiki/Host_Operating_System_Selection)
- [Whonix: connecting to a VPN before Tor](https://www.whonix.org/wiki/Tunnels/Connecting_to_a_VPN_before_Tor)
- [Whonix tunnel combinations and risks](https://www.whonix.org/wiki/Tunnels)
- [Tor Browser safety guidance](https://support.torproject.org/tor-browser/security/using-tb-safely/)
- [Oracle VirtualBox VBoxManage reference](https://docs.oracle.com/en/virtualization/virtualbox/7.2/user/vboxmanage.html)
- [Oracle VirtualBox Guest Additions and host integration](https://docs.oracle.com/en/virtualization/virtualbox/7.2/user/guestadditions.html)
- [Microsoft: Windows 10 end of support](https://support.microsoft.com/en-us/windows/deployment/updates-lifecycle/windows-10-support-has-ended-on-october-14-2025)

The pinned Whonix version, URLs, and signing-key fingerprint are stored in `config/release.json`. Treat updates to that file as security-sensitive changes.
