# Contributing

1. Keep claims measurable. Do not use “fully anonymous”, “untraceable” or similar language.
2. Do not add log wiping, Defender disabling, event-log tampering or destructive host tweaks.
3. Do not add a VPN provider, credential or certificate to the repository.
4. Preserve fail-closed behavior, Workstation internal-network-only routing and host-integration isolation.
5. Run `scripts\Test-RvbbitGhost.ps1` before opening a pull request.
6. Explain security-impacting changes in the pull request and update the threat model.

Use [GitHub Issues](https://github.com/buter-chkalova/rvbbit-ghost/issues) for non-sensitive defects. Follow [SECURITY.md](SECURITY.md) for vulnerabilities or reports containing sensitive information.
