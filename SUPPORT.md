# Support

Use [GitHub Issues](https://github.com/buter-chkalova/rvbbit-ghost/issues) for reproducible, non-sensitive defects in Rvbbit Ghost.

Do not post VPN profiles, credentials, assessment evidence, client information, source addresses, private logs, or security vulnerabilities in public issues. Follow [SECURITY.md](SECURITY.md) for private reporting.

Questions about Whonix, Tor Browser, OpenVPN, VirtualBox, or Windows that are not caused by this repository should be directed to the relevant upstream project.
